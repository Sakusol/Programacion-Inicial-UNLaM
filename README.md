# Programacion-Inicial-UNLaM
Repositorio con las prácticas y ejercicios resueltos para la materia Programación Inicial, cursada en la UNLaM durante el 2do cuatrimestre de 2026. Todo el código está escrito en lenguaje C.  El objetivo de este repo es documentar el recorrido de la materia, organizando los ejercicios por unidad temática a medida que se van viendo en clase.
