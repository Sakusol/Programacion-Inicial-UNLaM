# Programación Inicial - UNLaM

Repositorio con las prácticas y ejercicios resueltos para la materia **Programación Inicial**, cursada en la UNLaM durante el 2do cuatrimestre de 2026. Todo el código está escrito en lenguaje **C**.

El objetivo de este repo es documentar el recorrido de la materia, organizando los ejercicios por unidad temática a medida que se van viendo en clase.

## Estructura del repositorio

| Carpeta | Tema |
|---|---|
| [`01-estructura-secuencial`](./01-estructura-secuencial) | Programas con estructura secuencial: entrada/salida de datos, operadores aritméticos, conversión de tipos |
| [`02-estructura-decision`](./02-estructura-decision) | Programas con estructuras condicionales (if/else) para tomar decisiones según distintos casos |

*(se irán agregando más carpetas a medida que avance la cursada: condicionales, bucles, arrays, funciones, punteros, etc.)*

## Cómo compilar y ejecutar

Todos los ejercicios son archivos `.c` individuales. Para compilar y correr cualquiera de ellos:

```bash
gcc nombre_del_archivo.c -o programa
./programa
```
